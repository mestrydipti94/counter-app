# Counter App

A simple Counter App built using HTML, CSS, and JavaScript as a practice project.

## Features
- Increment counter
- Decrement counter
- Reset counter to zero

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Concepts Practiced
- DOM Manipulation
- Event Listeners
- Variables
- Click Events

## Purpose
Created as a beginner practice project to understand JavaScript fundamentals and DOM manipulation.
